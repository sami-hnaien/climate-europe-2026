# Power BI dashboard: data model and suggested pages

All files are in `data/processed/` and are regenerated by section 5 of `notebooks/00_full_project.ipynb`.
CSV format: UTF-8, comma separator, dot decimal, ISO dates. If Power BI types a column as text, set the
locale of the query to *English (United States)* (Transform data > column > Change type > Using locale).

## Tables

| File | Grain | Key columns |
|---|---|---|
| `regions.csv` | one row per NUTS 2 region (281) | `region_id`, `name`, `country`, `latitude`, `cluster`, `cluster_name`, `tg_trend_decade`, `tg_zscore_2026`, `tg_record_2026`, `tg_departure_from_trend_2026` |
| `indicators.csv` | region x year (1980-2026) | `region_id`, `year`, all summer indicators (see notebook data dictionary) |
| `trends.csv` | region x indicator | `region_id`, `variable`, `slope_decade`, `p_value`, `significant_fdr` |
| `daily_2026.csv` | region x day (Jan-Sep 2026) | `region_id`, `date`, `tg`, `tn`, `tx`, `rr`, `tg_clim`, `tg_anomaly` |
| `calendar.csv` | one row per day of 2026 data | `date`, `year`, `month`, `month_name`, `week`, `season`, `is_summer` |
| `europe_summary.csv` | year | area-weighted European means of the indicators |
| `pca.csv` | region | `region_id`, `pc1`, `pc2`, `cluster` |
| `cluster_profiles.csv` | cluster | mean of each feature per cluster |
| `regions_map.topojson` | region polygons (simplified) | property `region_id` |

## Relationships (Model view)

- `regions[region_id]` 1 -> * `indicators[region_id]`, `daily_2026[region_id]`, `trends[region_id]`, `pca[region_id]`
- `calendar[date]` 1 -> * `daily_2026[date]` (mark `calendar` as date table)
- `europe_summary` and `cluster_profiles` stay unrelated (small lookup tables).

## Suggested pages

1. **Overview 2026**: Shape Map (`regions_map.topojson`, location = `region_id`, colour = `tg_zscore_2026`), cards
   (Europe anomaly 2026, rank, number of record regions), bar chart of `europe_summary` by year.
2. **Daily 2026 (date slicer)**: slicer on `calendar[date]` (between), line chart of `tg` and `tg_clim` per day,
   map coloured by average `tg_anomaly` over the selected dates, region slicer.
3. **Trends**: map of `tg_trend_decade`, slicer on `trends[variable]`, scatter `latitude` vs `slope_decade`.
4. **Clusters**: map coloured by `cluster_name`, scatter `pca[pc1]` vs `pc2` coloured by cluster, table of `cluster_profiles`.

Shape Map is a preview visual: enable it in File > Options > Preview features, then Format > Map settings > Custom map.
